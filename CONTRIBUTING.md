# Guía de contribución

Estas pautas te ayudarán a que el proceso de contribución sea sencillo y transparente.

## ¿Cómo puedes ayudar?
* Reportando **errores** (bugs) mediante los *Issues*.
* Proponiendo **nuevas características** o mejoras.
* Corrigiendo errores y enviando código a través de *Pull Requests*.

## Reportar un error
1. Revisa si el error ya fue reportado en la pestaña de *Issues*.
2. Si es nuevo, crea un *Issue* describiendo el comportamiento actual y el esperado.
3. Añade los pasos necesarios para reproducir el fallo.

## Enviar un Pull Request (PR)
1. Realiza un **Fork** del repositorio principal.
2. Crea una rama nueva para tu función o corrección:
   `git checkout -b feature/nueva-funcion`
3. Haz tus cambios y confirma los mensajes de manera clara:
   `git commit -m "Agrega función X"`
4. Envía tu rama al repositorio remoto:
   `git push origin feature/nueva-funcion`
5. Abre un **Pull Request** hacia la rama principal (`main`).
